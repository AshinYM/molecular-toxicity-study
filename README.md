# 분자 독성 예측 — 표현 손실과 일반화 검증

SMILES 기반 입체 정보와 기존 fingerprint의 표현 충돌을 조사한 EDA 및 LightGBM 모델링 검토본입니다.

## 읽는 순서

1. `01_eda.ipynb`: 원본 라벨·입력 구조·상수·충돌 조사
2. `02_modeling.ipynb`: Original/Morgan/Morgan8 비교, scaffold 분리와 임계값 평가

모델링 라벨은 **0=독성, 1=비독성**입니다. 기본 양성 클래스 F1을 독성 탐지 F1로 혼동하지 않습니다. 반전 라벨을 쓰는 별도 EDA 버전은 포함하지 않았습니다.

## 재현 조건과 한계

데이터는 포함하지 않습니다. 이용 권한이 있는 `train.csv`, `predict_input.csv`와 예측 출력 형식 예제를 노트북이 찾는 경로에 별도로 준비해야 합니다. Python 환경에서 pandas/numpy/matplotlib/seaborn/scikit-learn/lightgbm/RDKit가 필요하며, 정확한 의존성 잠금과 전체 재실행은 후속 작업입니다.

과거 기록에서는 입체 정보 보존이 입력 충돌을 줄였지만 일반화 성능 향상을 보장하지 않았습니다. 전체 라벨을 보고 선택한 지역 입체 변수의 선택 편향은 scaffold 분리만으로 제거되지 않습니다. 다음 실험은 변수 선택·튜닝·임계값 선택을 학습 fold 내부에 넣어야 합니다. 저장된 과거 점수를 독립 검증 완료로 소개하지 않습니다.

## 출처와 개인 개선 기록

이 저장소는 기존 학습·팀 프로젝트에서 포트폴리오 후보를 선별한 **공개 포트폴리오 출발본**입니다. 사용자 확인에 따라 공개하되, 수업·팀 프로젝트를 기반으로 한 응용임을 밝힙니다. 전체를 처음부터 독자 구현했다고 주장하지 않습니다. 개인 개선은 커밋과 검증 결과로 구분해 쌓아갑니다. 원저작물에 임의의 라이선스를 부여하지 않았습니다.

교안·녹취록·실제 데이터·모델 파일·DB·API 키·실행 출력은 포함하지 않습니다. 노트북 출력은 제거했습니다. 과거 결과는 이번 재실행 결과가 아닙니다.
